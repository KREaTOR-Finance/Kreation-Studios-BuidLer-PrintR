# PrintR — Micro Animations & Feedback Spec

## Commit
- Sonar ring expand (180ms)
- Lightning tick flash (80ms)
- Fade to ghost marker (200ms)
- Total 350–450ms
- Neutral/accent color

## Close
### Gain
- Green +$ float up
- Marker flashes green
- Score ticks up smoothly

### Loss
- Red -$ float down
- Marker flashes red
- Score ticks down smoothly

## Haptics/SFX
- Commit: short crisp tap + soft ping
- Close gain: gentle upward sweep + clean positive tick
- Close loss: sharp tap + lower click
