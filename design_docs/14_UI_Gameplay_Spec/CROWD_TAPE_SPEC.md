# Crowd Tape (Final Commit Window) – Spec

## Purpose
During the **FINAL_COMMIT_WARNING** (last 30 seconds before CLOSING), display a trading-style **Crowd Tape**
showing aggregated player actions in near real-time. This increases:
- excitement / urgency
- social proof (“crowd leaning long/short”)
- learning for spectators

**Scope constraint:** The tape is enabled ONLY in the 30-second warning window.

## When it appears
State: `FINAL_COMMIT_WARNING`  
Duration: `T-30s` → `T-0` (transition into CLOSING)

Tape is disabled in:
- LIVE (0–18 minutes)
- CLOSING (last 2 minutes)
- ENDED

## Tape Event Types
Events appear as compact “prints” (broker tape style):

1) **COMMIT (OPEN)**
- Direction: LONG / SHORT
- Leverage: x1–x5
- Size bucket: Small / Med / Large (optional)
- Player display: anonymous / opt-in identified (see Display Modes)

Example:
- `🐝 Trader-1842  LONG  x3  +MED`
- `⚡ Wolf-7721   SHORT x5  +L`

2) **CLOSE**
- Result bucket: WIN / LOSS
- Delta bucket: +S / +M / +L or -S / -M / -L (optional)

Example:
- `🟢 Trader-1842  CLOSE  +M`
- `🔴 Wolf-7721    CLOSE  -S`

3) **BREAK / FORFEIT** (rare)
Example:
- `⚠️ Bear-2301 BREAK`
- `☠️ Otter-9910 FORFEIT`

## Display Modes (Optional Configurations)

### Mode A (Default): Anonymous Handles (Recommended)
- Show: autogenerated handle (e.g., `Trader-1842`)
- Show: tier icon (optional)
- Do NOT show wallet

### Mode B (Opt-in Profile Identified)
- User can toggle: “Show my profile publicly”
- Shows: chosen display name + tier icon + 1 trophy badge
- Still DO NOT show full wallet

### Mode C (Advanced): Short Wallet Hash in Modal Only
- Tape shows handle
- If user taps a tape line: opens mini profile sheet
- Sheet may show wallet short hash: `9f3A…kP2`
- Never show full address in tape

### Mode D (Private Rooms – Future)
- In private tournaments / groups, allow fuller identity (still recommend shortened wallet only)

## UI Placement (Mobile)
In FINAL_COMMIT_WARNING:
- Tape appears as a thin overlay on the chart edge (top-right or bottom-right), OR
- As a small docked panel above the control console

**Rules:**
- Must not cover chart significantly
- Auto-fades old prints after 6–10 seconds
- Update on tick (5s) OR “burst” within window (1s batch)

## Anti-Spam & Fairness
- Rate limit prints per player (e.g., 1 per tick)
- Collapse repeated same-direction commits into aggregated print if needed

## Copy / Labels
Banner during window:
- `FINAL 30s — LAST CHANCE TO COMMIT`

Tape header (tiny):
- `CROWD TAPE`
