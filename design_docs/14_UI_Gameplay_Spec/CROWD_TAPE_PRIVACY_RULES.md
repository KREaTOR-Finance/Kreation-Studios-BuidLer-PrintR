# Crowd Tape – Privacy & Safety Rules

## Default rule (public sessions)
- Do NOT display full wallet addresses.
- Do NOT display user personal data.
- Default identity is anonymous handle.

## Opt-in identity
Users may opt-in to show:
- display name
- tier icon
- a single badge

Wallet display rule:
- If shown at all, show ONLY a short hash form (e.g., `9f3A…kP2`)
- Only visible inside a detail sheet/modal (not on tape line)

## Controls
- User setting: "Public identity on tape" (default OFF)
- User setting: "Allow profile tap-through" (default ON)

## Data retention
- Tape lines are ephemeral (UI-only)
- Do not store a public permanent feed by default
- For analytics, store only aggregated counts unless user opts-in

## Rationale
Keeps crowd excitement while reducing harassment/tracking risk.
