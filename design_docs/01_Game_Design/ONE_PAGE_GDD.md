# BuidLer PrintR — One Page Game Design Document

PrintR is a live, arcade-style, skill-based game inspired by market motion visuals.
Players earn points, mastery, and reputation through timing and decision-making,
not money or speculation.

The game runs as continuous live Asset Sessions, each shared by all players.

Core Pillars:
- Skill over luck
- Fast resolution
- Parallel play
- Creative identity
- Zero financial pressure
