## Layout grid
- Margin: 16
- Columns: 4
- Gutter: 12
- Use 8pt spacing system

## Common UI regions
- Top Bar (56): points + streak + settings
- Main Panel (flex): primary interaction (buttons/chart)
- Bottom CTA Area (96): primary CTA button

## Auto-layout rules
- Cards: vertical auto-layout, padding 16, gap 12, radius 18
- Buttons: min height 52, padding 14×16, radius 14
- Direction buttons row: 2 equal buttons, gap 12

## Visual style
- Background: midnight gradient (subtle radial)
- Cards: glassy panel with neon edge highlight
- Win effects: confetti + green glow
- Miss effects: calm red glow + “so close” text
