# Brand System Rules (One Universe)

## Rule 1 — Tokens drive everything
Use shared tokens and CSS vars; avoid random colors.

- Tokens: `frontend/src/theme/tokens.ts`
- Global CSS: `frontend/src/styles/site.css`

## Rule 2 — Site and game share the same voice
- Kreation Studios: umbrella brand
- PrintR by BuidLer Labs: premier title
- Language: broker-style, fast, trust-first, premium

## Rule 3 — Keep CTAs consistent
Primary CTA: gradient button
Secondary CTA: bordered button

## Rule 4 — Never “trap” the user
From anywhere in the site, you can:
- Play PrintR
- Buy sessions
- View support/legal
