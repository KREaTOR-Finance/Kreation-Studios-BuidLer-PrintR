# Player Profile (PrintR)

A persistent identity layer tied to Telegram ID + Solana wallet.

## Core stats
- Lifetime points
- Sessions played
- Best session score
- Best single position
- Win rate
- Avg points per marker
- Avg leverage
- Break Point hits
- Forfeit count (unclosed positions at end)
- Creator stats (assets created, joins, retention)

## Display
- Pinned badges (max 6)
- Pinned trophies (max 3)
- Season rank + lifetime rank
- Recent history (last 10 sessions)
